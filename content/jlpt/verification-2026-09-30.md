# IndexedDB 브라우저 검증 및 N5 두 번째 묶음

2026-09-30. 로컬 Vite 개발 서버와 별도 Chromium 테스트 프로필에서 확인했다. 공개 사이트 배포 검증은 아니다.

## 저장·학습·백업

- 새 프로필에서 홈과 N5 학습 설정, 세션 시작 확인. 초기 화면 스크린샷 `output/playwright/idb-home.png` 확인, Vite 오류 화면 없음.
- 힌트와 정답 공개를 각각 실행하고 새로고침한 뒤 세션 데이터 일치 확인.
- `앎` 판정 뒤 프로필 생성, 새로고침 후 판정 상태 유지, `이전 카드`로 이전 상태 복원 확인.
- 테스트 DB만 비우고 실제 내보낸 v2 문자열을 이전 저장 키에 넣어 이전 재현. 기존 문자열을 DB의 원본 영역에 그대로 보존하고, 작은 이전 완료 표시로 키를 전환하며, 다시 내보낸 학습 상태가 원본과 일치함을 확인.
- 화면의 `앱 파일로 저장`으로 내려받은 파일을 `앱 저장된 파일에서 불러오기`와 앱 내 `복원` 버튼으로 복원. 세션·힌트·정답 공개·설정 일치 확인. 내부 revision은 복원 보호를 위해 5→7로 증가했으며 학습 내용은 같았다.
- 같은 브라우저의 두 탭을 같은 상태에서 열어 한 탭에서 저장 후 다른 탭의 저장 거부 확인. 오류 표시와 재hydrate 후 회복 확인.
- 파일 선택기와 자동 새로고침이 겹쳐 CLI의 모달 추적이 남는 현상이 있었다. 새 탭에서 같은 DB를 읽어 복원 결과를 별도로 대조했다. 앱의 복원 실패로 처리하지 않았다.

재현 스크립트와 내려받은 테스트 백업은 무시되는 `output/playwright/`에 있다. 이 검증은 현재의 소규모 실제 콘텐츠와 테스트 기록을 사용했다. 12,000어휘의 실제 기기 성능, 대용량 QR 제한 화면, 복원 중 브라우저 강제 종료는 아직 이 브라우저 검증에 포함하지 않았다. 복원 중단·롤백은 기존 자동 테스트가 담당한다.

## N5 추가 40개

- N5 20→60개, 전체 신규 100→140개, 신규 예문 300→420개. 기존 포함 1,648단어·3,436예문.
- 물건·음식·교통·시설·생활을 다루는 40개 항목의 읽기·한국어 뜻·독립 힌트·구별 설명·예문 각 3개를 작성했다.
- コート·バス·パン·フォーク의 동음어 사전 ID를 명시하고, シャツ는 첫 번째 속옷 의미가 아닌 두 번째 겉옷 의미를 채택했다. ストーブ는 난방용 난로로 한정했다.
- 엘리베이터 첫 예문이 기존 자전거 예문과 가린 문장 유사도 0.7이어서 장면과 구문을 다시 작성했다.
- 같은 AI의 별도 재검토 후 각 원고 해시에 승인 기록을 연결했다. 사람 전문가 검수로 표시하지 않는다.
- 전체 예문 감사: 누락 0, 높은 유사도 0, 반복 도입·결말 검토 대상 0, 후보 쌍 비교 26,010회.
- 가져오기 도구는 이전 게시 목록과 편집기 소속 목록이 일치하고 기존 항목의 순서·소속을 유지할 때만 새 항목을 뒤에 추가한다. 수정된 편집기 소속, 기존 항목 삭제·재배열, 중복 삽입을 차단한다.
- 가져오기 경계 및 전량 3예문 순환 검사 2파일·9테스트 통과. 에디터 정규화의 전역 배열 순서와 ID 보존은 구분하고, 단어장 내부 순서는 별도로 확인한다.
- 빌드 통과. main JS 약 2.25 MB / gzip 542 kB로 분할 로딩 작업은 여전히 필요하다.

전체 12,000개·신규 10,000개 목표는 미완료이며 아직 commit/push/게시하지 않았다.

## 학습 예문 분할 로딩

- 신규 514개를 포함한 빌드에서 생성된 128개 예문 묶음을 실제 Chromium으로 검사했다. 홈과 학습 설정에서는 예문 묶음을 내려받지 않는다. N4 첫 카드에서 필요한 묶음 1개만 내려받았고 전송량은 3,618바이트였다.
- 독립 힌트·정답 공개·다음 카드·새로고침 복원·undo 확인.
- 예문 파일 요청을 강제로 차단하여 오류 화면과 판정 차단을 확인했다. 같은 URL의 실패한 동적 import가 브라우저에 남는 문제를 발견해 다시 불러오기를 기록 보존 새로고침으로 수정했다.
- 수정한 빌드에서 4번째 카드 판정 후 5번째 카드 다운로드를 차단했다. 차단 해제 후 다시 불러오기로 정확히 5번째 카드가 복원됐으며 undo는 4번째 카드로 돌아갔다. 이 과정의 미처리 브라우저 오류는 없었다.
- 스크린샷 `output/playwright/shard-home.png`, `shard-restored.png`는 무시되는 검증 산출물이다. 빌드 통과. 테스트 182개 중 에디터 초기 렌더 1건이 동시 부하에서 시간 초과했고 단독 재실행 8건은 통과했다. 이후 재시도 보강 검사 13건 통과.
- 최근 8개 묶음의 조회 맵 캐시와 브라우저 자체의 모듈 캐시는 다르다. 이 결과는 전체 목표 수량의 메모리·기기 성능 통과를 의미하지 않는다.
