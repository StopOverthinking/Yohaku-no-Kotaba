# JLPT 확충 작업 원장

## 현재 상태

**실용 어휘 선정과 최종 로컬 검증을 완료했다.** N5 599개 · N4 648개 · N3 1,727개 · N2 1,056개 · N1 831개, 고유 수록 **4,861개**. 실제 신규4,114개와 기존 ID 재사용747개를 구분한다. 수준별 선택 예문8,068개, 앱 전체5,635단어·5,658용법·9,616예문이다.

사용자가 조정한 약5천개 범위에서 수량보다 활용도·수준별 누락을 검토해 확정했다. `scope.json.finalSelection`과 [현재 자동 집계](progress.json)의 원장 해시가 일치해야 승인된다. 최종 누락0·자동 유사쌍0, 남은 반복 도입1/결말10그룹은 실제 장면을 독립 검토했다. 기존 분류47파일 구조 오류0, 원고207부분 출처/승인/반영 대기0. 전량233검사 통과 뒤 최종 규모의 관련54검사와 마지막 예문 정정 후11검사를 재확인했다. 실제 브라우저 전량 프로필·500판정/500undo·백업·128묶음·27그룹 이전을 통과했다. 모바일 Chromium 에뮬레이션 카드/undo p95 65.6/62.4ms, N3 검색120.1ms, 초기5회656.7ms/재방문25회129.1ms. 실제 휴대폰/Safari 성능을 주장하지 않는다.

기존1,508개 ID와 기존 핵심 용법/학습 기록을 보존했다. 승인된 설명 정정·추가 용법·예문 개정은 원본/수정본 및 독립 검토 이력에 남겼다. 선택하지 않은 원본을 삭제하거나 모든 뜻을 같은 숙련도로 합치지 않는다. 대표 예문 최소1개, 이미 작성된2·3개 예문은 유지한다.

[최종 선정 근거와 제외 범위](final-selection-review.md), [최종 브라우저 검증](benchmarks/2026-10-01-browser-scale.md), [시간/작업량](benchmarks/2026-10-01-efficiency.md), [전량 원고 해시 대조](benchmarks/2026-10-01-batch-provenance.json)를 따른다. 실용 모음이며 전체 시험 어휘·사전 의미·문법 패러다임의 완전 수록을 주장하지 않는다.

콘텐츠 원장의published는 로컬 앱 반영을 뜻한다. 실제 공개 버전은 GitHub Pages `release.json`의 커밋과 HTML 해시로 별도 확인한다. Pages CI는 전량 회귀·콘텐츠 감사·현재 독립 선정 승인을 요구한다.

## 파일

- `baseline.json`: 확충 전 단어 ID·표기·읽기 및 파일 해시. 신규 수 집계를 위해 다시 만들지 않는다.
- `candidate-manifest.json`: JMdict 다운로드 해시, OpenJLPT 커밋 및 후보 통계.
- `candidates/*.json`: 사전 기반 후보. 한국어·문장·수준 판정이 끝난 데이터가 아니다.
- 기존 후보 스냅샷의 `three-authored-examples`는 과거 계획의 메모다. 현재 작성·검사 기준은 대표 용법별 검토 예문 1개 이상이며, 후보 재생성기는 `representative-example`로 기록한다.
- `pilot/n5.txt`~`n1.txt`: 단어마다 메타데이터 1행과 검토한 대표 예문 1개 이상. 기존 2·3개 예문은 보존한다. 《 》는 빈칸 정답 및 번역 강조 구간.
- `pilot/reviews.json`: 내용 해시에 연결한 AI 재검토 기록. 사람 전문가의 검수 기록이 아니다.
- `pilot/published.json`: 로컬 앱으로 가져온 시범 데이터의 출처와 해시. 여기서 published는 로컬 생성 데이터 포함을 뜻하며 웹 배포와 다르다.
- `pilot/similarity-review.json`: 기존 코퍼스까지 대조한 유사 문장 검토 결과.
- `UPSTREAM-NOTICE.md`, `UPSTREAM-LICENSE`: OpenJLPT의 원본 출처·라이선스 고지.

## 시범 콘텐츠 검토에서 고친 점

- アルバイト는 아르바이트와 광물 albite가 같은 표기·읽기이므로 사전 ID를 명시했다.
- 基盤은 기반·토대 의미를 선택했고 회로 기판 항목과 구분했다.
- 見直す는 이 용법에서 타동사다. 시장·상태가 회복된다는 별도의 자동사 의미를 합쳐 품사를 표시하지 않는다.
- 기존 署名·締め切り 예문과 가린 문장이 유사했던 名前·受付 문장을 다시 작성했다.
- 逸脱·顕著·緻密은 채택한 분류표에 연결되는 등급이 없어 추상적·격식적 용법을 근거로 N1 권장 수준을 부여했다. 공식 등급을 주장하지 않는다.
- 문장 난도는 기존 10~59 척도를 참고한 초기 편집 추정이다. 선택한 의미의 수준 재검토와 전량 학습/예문 순환을 완료했으며 사용자 점수를 시험 합격 등급으로 보지 않는다.

## 작업 경로

1. `output/jlpt-sources`에 JMdict_e.gz 및 OpenJLPT의 커밋이 고정된 N5~N1 JSON·NOTICE·LICENSE를 저장한다. 실행한 출처는 manifest에 기록되어 있다. 내려받은 코드는 실행하지 않는다.
2. `npm run jlpt:prepare`: 원본 사전에서 후보 풀을 만든다. 수준 추정은 의미 검토가 필요하다. 특히 읽기가 비어 있는 상위 목록의 표기만으로 사전의 동형이의어 수준을 확정하지 않는다.
3. `npm run jlpt:pilot`: 작성 원고를 구조 검증한 뒤 `output/jlpt/pilot-draft.json`에 초안으로 변환한다. 검수 완료로 자동 승격하지 않는다.
4. 내용 검토 후 현재 해시에 대한 검수 기록을 작성한다. 원고가 바뀌면 해시도 바뀌므로 이전 승인으로 가져올 수 없다.
5. `npm run jlpt:pilot -- --publish` 및 `npm run extract:vocab`: 검토한 시범 원고를 원본 JSON과 런타임 TS에 반영한다. 기존 ID 충돌·에디터 변경이 있으면 덮어쓰지 않고 중단한다.
6. `npm run jlpt:audit`, `npm run audit:content`, 관련 테스트와 빌드를 실행한다.

기존 고유 어휘는 별도의 독립 참조 승인을 받은 뒤 기존 ID 그대로 수준별 단어장에 연결한다. 이때 원본 단어·용법·예문과 학습 기록은 유지한다. 중복 정규형/별칭 그룹과 프로필 통합은 이 경로에서 거부하며 별도 검토 대상이다. 상세 계약은 [기존 어휘 검토](legacy/README.md)를 따른다.

## 이용 조건

이 폴더의 사전 파생 후보·신규 수준별 어휘 및 해당 한국어 학습 콘텐츠는 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)을 따른다. JMdict는 James William BREEN 및 EDRDG의 자료이며 [이용 조건](https://www.edrdg.org/edrdg/licence.html)에 따라 사용한다. OpenJLPT와 Jonathan Waller의 수준 분류를 출처로 기록한다. 외부 예문은 신규 원고에 복사하지 않았다.

원본 갱신은 manifest의 버전·해시와 비교하고, 변화가 있는 항목을 검토한 뒤 반영한다. 후보 재생성이 편집 원고·검수 기록·앱 데이터를 덮어쓰지 않는다. 이용자용 출처는 홈 정보 아이콘에서 `sources.html`로 연결한다.

## 후속 갱신 규칙

확정 콘텐츠를 바꾸면 해당 원고·출처·독립 검토·정정 이력과 최종 선정 해시를 함께 갱신한다. 새 후보나 단순 수량 도달을 완성본으로 취급하지 않는다. 과거 단계는 [진행 이력](implementation-progress.md)에 보존한다.
