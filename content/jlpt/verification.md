# 시범 100개 검증 기록

검증일: 2026-09-29. 로컬 변경이며 배포 결과가 아니다.

## 콘텐츠

- N5~N1 각 20개, 신규 100개, 예문 300개. 현재 앱 전체는 1,608단어·1,608용법·3,316예문이다.
- 원고의 읽기·의미·품사를 JMdict와 대조하고 별도 AI 편집 검토를 거쳤다. 사람 전문가의 검수를 주장하지 않는다.
- 시범의 모든 단어가 실제 학습 엔진에서 출제되고, 서로 다른 날짜에 세 예문이 순환한다는 자동 테스트를 통과했다.
- 전체 콘텐츠 구조 감사: 누락 0, 가린 문장 유사 후보 0. 유사성 계산 23,604회. 자동 검사가 자연스러움·오역 부재를 보증하지는 않는다.
- 시범의 승인 해시와 현재 콘텐츠를 비교하고, 에디터가 바꾼 항목을 다시 가져올 때 덮어쓰기를 거부한다. 같은 원고 재실행은 중복을 만들지 않는다.

## 실행 검증

- 전체 테스트: 31파일, 135개 통과.
- TypeScript 검사·배포용 빌드 통과. 약 2.18MB의 메인 JS와 500kB 초과 청크 경고가 남아 있다.
- 브라우저에서 N5~N1 대표 항목의 시작·힌트·정답 공개·판정·완료를 확인했다. 새로고침 후 같은 카드와 힌트를 복원했다.
- 390×844 화면에서 가로 넘침이 없었다. 실제 모바일 기기나 모바일 터치 성능 측정은 아니다.
- 키보드 Space 공개, 오른쪽 모름 후 재학습, 왼쪽 앎 후 완료를 확인했다.
- 완료 화면에서 결과를 비울 때 학습 설정으로 되돌아가던 문제를 수정했다. 실제 홈 이동 및 출처 페이지 연결을 다시 확인했다.

## 대량 상태 검증과 한계

합성 12,000단어·36,000예문·12,000프로필을 넣고 500회 판정, 직렬화·재복원, 연속 500회 undo를 통과했다. 이는 데이터 보존과 순수 엔진 연산을 보는 테스트이며 실제 콘텐츠 완성 수와 무관하다.

최종 전체 테스트와 함께 실행한 측정에서는 엔진 판정 p95 57.93ms, 직렬화 문자열 4,375,555자였다. 앞선 단독 실행에서는 약 22ms가 나왔으므로 병렬 작업 부하에 따라 달라진다. UI 표시·브라우저 저장·네트워크 시간은 측정에 포함되지 않는다. 전체 학습 조작 p95 목표를 달성했다는 의미가 아니다.

전체 확장을 위해 분할 로딩, IndexedDB·백업 개선, 실제 기기 측정이 필요하다. 12,000개 수록과 신규 10,000개 목표, 기존 어휘 분류·세 번째 예문 보강은 미완료다. `progress.json.complete`는 false를 유지한다.
