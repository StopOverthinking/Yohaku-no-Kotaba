# 기존 단어 참조 에디터 확인

2026-09-30, 로컬 Vite + Chromium, 테스트 전용 메모리 자료로 확인했다. 실제 편집 원본이나 학습 기록에는 참조를 추가하지 않았다.

- 기존 `JLPTN3_1`, `JLPTN3_2`를 참조하는 별도 단어장의 두 행이 표시됐다.
- 행 아래로 이동 후 참조 목록만 순서가 바뀌었다.
- 참조 행 삭제 후 참조 수는 2→1, 원본 단어장 500개와 전체 단어 수는 유지됐다.
- 다른 단어장이 참조 중인 원본 단어 및 원본 단어장 삭제는 각각 안내를 표시하고 거부했다.
- xlsx 생성 결과의 `_membershipMode=explicit`, 원본 ID·소속·순서를 확인하고 실제 파일 입력으로 다시 가져왔다. 참조 2개, 원본 500개 및 전체 단어 수가 유지됐다.
- 참조 행 복제는 현재 참조 단어장 소유의 새 ID `jlptn3-1-copy`를 만들고 원본 ID 두 개를 보존했다.
- 페이지 로드 및 위 동작에서 수집된 브라우저 오류는 없었다.

자료: `output/playwright/reference-editor-smoke.html`, `reference-roundtrip.xlsx`, `reference-copy.png`.

경계: 브라우저 도구의 직접 다운로드는 취소되어 OS 파일 저장 성공을 확인하지 못했다. 대신 실제 내보내기 버튼이 만든 Blob을 검사 파일로 저장하여 업로드·재가져오기를 검증했다. 테스트에서 다운로드 링크 실행과 alert/confirm만 대체했다. 디렉터리 쓰기 및 실제 수준별 참조 활성화는 별도 단계다.
