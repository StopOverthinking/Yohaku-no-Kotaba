# 대표 40개 단어 / 80문장 검수

2026-09-28, Astra 자체 작문·검수. 원어민의 외부 감수를 받았다는 의미는 아니다.

## 단어와 활용형

`pilot.tsv`의 40개 행을 대상으로 정답 경계, 활용형 읽기, 일본어 문장과 한국어 번역의 시제·부정·말투를 확인했다. 답안 앞뒤 문자열은 목표 활용형 전체를 제외한 문맥이다. 한국어 강조는 번역 안의 실제 구간으로 지정했다.

- `怪しい`: 번역의 ‘은행을 사칭하는’을 ‘은행에서 보냈다는’으로 수정했다. 원문은 명의를 내세웠음을 말하며 사칭을 확정하지 않는다.
- `薄い`: 여름 이불로 교체해서 벽장 공간이 늘어난다는 예문의 상황이 명확하지 않아, 여행용 수건이 얇아 빨리 마르는 장면으로 교체했다.
- `易しい / 優しい`: 발음은 같지만 난도와 성품을 구별하도록 장면과 힌트를 작성했다.
- `我慢`: 명사 자체를 빈칸으로 두고 문맥의 조사·가능 표현을 유지했다.

## 혼동 표현

- `預ける / 預かる`, `貸す / 借りる`: 물건을 맡기거나 빌리는 방향을 주어와 수혜 관계로 검토했다.
- `輝く / 光る`: 찬란함과 단순한 발광의 인상을 대비했다. 강도의 차이만으로 언제나 유일한 정답이 된다고 주장하지 않는다.
- `景色 / 風景`: 쓰임이 겹친다는 점을 힌트에 보존했다. 사진 속 옛 거리와 생활 장면도 활용했다.
- `懐かしい / 恋しい`: 과거 경험이 되살아나는 느낌과 현재 떨어진 대상을 그리워하는 마음을 대비했다.
- `詳しい / 細かい`, `確実だ / 正確だ`, `簡単だ / 易しい`: 이번 대표 용법을 좁혀서 정보량·크기, 확실성·오차, 절차·난도를 구별했다.
- `必ず`, `相変わらず`, `次第に`, `突然`: 약속, 예전과의 비교, 변화의 진행, 뜻밖의 발생을 각각 문맥에 반영했다.

힌트의 일본어 표기 노출은 없으며, 혼동 표현의 일본어 표기는 편집 자료에만 둔다. 나머지 대표 용법도 연결된 혼동 표현과 차이를 행별로 검토했다.

## 장면 다양성

게임, 식사, 숙소, 산, 반지, 표시등, 고양이, 편지, 유학, 원고, 시험, 약, 교통, 시장, 수리, 치과, 가족, 도서관, 강, 조립, 위생, 음악 등으로 장면을 분산했다. 두 예문은 대상 이름만 바꾼 복제가 아니도록 질문·대화·관찰·부탁·회상·판단을 섞었다.

80문장 대상 자동 점검: 같은 빈칸 문장 0건, 문자 2-gram 유사도 0.7 이상 0쌍, 같은 8글자 도입/결말 5회 이상 0그룹. 이 수치는 의미와 자연스러움 검수를 대체하지 않는다.
