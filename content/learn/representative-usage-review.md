# 대표 예문의 독립 학습과 자연스러움 정정 (2026-10-20)

사용자 요청: `店の表` 같은 덜 일상적인 문맥을 정정하고, 같은 단어의 여러 예문이 학습·복습에서 섞이는 문제를 해결한다. 내부 검증 후 push·게시하며 공개 사이트의 게시 결과 테스트는 수행하지 않는다.

## 범위

- 복수 예문 원본 190용법·406예문을 기존 `example-pruning-review.json`의 의미 분류와 전부 대조했다. 기존 彼女 정의는 유지하고 나머지 189용법을 추가 분리했다.
- `editor-data/senseSeparations.json`에 예문 ID와 의미·힌트를 명시했다. 런타임 5,874용법은 모두 대표 예문 하나만 갖는다. 분할 정의 누락이나 예문의 중복 소속은 생성을 차단한다.
- 원본 5,635단어·5,658용법·5,874예문과 ID·소속·순서·용법 버전은 유지한다. 의미 구별이 흐리거나 표현이 어색한 9예문만 정정하고 해당 예문 버전을 1 올렸다. 전후 원문과 해시는 `example-corrections/2026-10-20-naturalness.json`에 보관한다.
- 현재 세션의 사용자 요청에 따른 편집 검토다. 과거 독립 승인 해시는 유지하고 검증 입력에서만 당시 원문을 복원한다. 나머지 단일 예문 5,468개는 구조·생성·후리가나·정답 노출 감사를 수행하며 새 언어 전수 승인으로 표현하지 않는다.

## 문장 정정

| 대상 | 정정 내용 |
| --- | --- |
| 表 | `店の表で友達を待っていました。` → `少し表に出て、風に当たってきます。` |
| 隠す | 꽃병을 숨기는 문장 → `失敗したことを家族に隠した。`: 물건과 사실 은폐 구별 |
| 高い | 산을 주제로 높이 올라갈 수 있다는 문장 → `飛行機は雲より高い所を飛んでいます。` |
| 隣 | `隣の家から` → `隣から`: 단어 자체의 이웃집 의미 |
| 代わり | `送ってくれた代わりに` → `送ってもらった代わりに`: 도움을 받은 화자의 보답 관계 |
| 元 | `棚の元の場所` → `元の場所`: 수식 중첩 정리 |
| 熱 | 냄비의 열이 식을 때까지 뚜껑을 열지 않는 문장 → `鍋の熱が手に伝わってきました。` |
| どんなに | 연습량 질문 → `会える日をどんなに楽しみにしていたことか。`: 정도를 강조하는 감탄 |
| 休み | `午後の休み` → `昼の休み`: 점심 휴식 문맥 |

`表に出る`는 [문화청의 구어 설명](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/series/33/pdf/kokugo_series_033_03.pdf)과 [Cambridge의 바깥 용법](https://dictionary.cambridge.org/dictionary/japanese-english/%E8%A1%A8)을 참고했다. `店の表`를 문법적으로 불가능하다고 판단한 것은 아니다. 학습용 자연스러움에 맞춰 문맥을 바꿨다.

## 기록 보존

기존 통합 일정은 마지막 예문의 소속에만 연결하며 다른 의미로 복제하지 않는다. 원래 프로필·노출·undo는 보관하고 기존 彼女 분리 기록도 그대로 읽는다.

기존 동일 용법 연결 27그룹 중 `助ける` 한 그룹이 추가 분리 대상과 겹친다. `AbsoluteVerb_461`의 도움 예문을 명시적 원본 해시·예문 연결로 `handmade_2`의 도움 용법에만 대응시키고 구조 용법에는 연결하지 않는다. 이미 병합된 기록과 병합 전 기록을 모두 처리하며, 삭제된 예문도 기존 삭제 이력으로 소속을 찾는다. 연결 그룹 정의·보관 키는 유지하고 DB 저장 실패 시 이전 전체 기록을 보존한다.

분리된 용법은 통합 비교어를 상속하지 않는다. 단어 목록의 통합 뜻과 단어 전체의 복습 대기·삭제 규칙은 유지한다.

발음 감사는 새 원문 해시로 과거 검토본을 덮어쓰지 않는다. 검증된 후속 정정 이력으로 당시 스냅샷을 복원해 기존 204구간을 확인하고, 현재 원본도 따로 생성하여 읽기 누락을 검사한다.

## 같은 작업 폴더의 후속 정정

이 작업의 최종 검증 도중 별도 사용자 요청의 `戸` 예문 정정이 같은 폴더에 추가되었다. `example-corrections/2026-10-20-to-door-context.json`의 독립된 전후 이력을 보존하고 최종 생성·검증·게시 범위에 함께 포함한다. 이 작업의 9예문 정정과 구분하며 현재 누적 정정 수는 이전 295개 + 이번 9개 + 戸 1개 = 305개다.

`穏やか`는 사용자 추가 지정을 별도 회귀 검사로 보강했다. 말투·태도와 바다·환경의 의미·힌트·대표 예문·복습 기록을 각각 확인한다. 로컬 빌드의 390×844 화면에서 바다 예문의 모름 재학습·새로고침 뒤에도 해당 예문과 프로필 하나만 유지되며 가로 넘침이 없음을 확인했다. 공개 사이트 검증은 수행하지 않는다.
