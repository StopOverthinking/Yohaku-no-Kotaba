# 비슷한 단어 힌트의 정답 한자 노출 정리

2026-10-07 사용자의 요청에 따라 전체 **5,635단어·5,658용법·5,874예문**의 비교어를 조사했다. 선택 자료가 있던 3,906용법뿐 아니라 기존 대비 표현을 사용하던 1,752용법도 포함했다.

## 조사 결과

| 항목 | 수량 |
| --- | ---: |
| 기존 화면 비교어 항목 | 9,473 |
| 정답의 한자 또는 같은 표기를 드러내는 항목 | 3,200 |
| 영향받은 단어 / 용법 | 2,664 / 2,667 |
| 수정 후 비교어 항목 | 7,862 |
| 수정 후 정답 노출 항목 | 0 |
| 안전한 비교어가 있는 용법 | 4,784 |
| 한국어 힌트만 표시하는 용법 | 874 |

항목 수는 용법별 표시 횟수다. 같은 비교어가 여러 용법에 있으면 각각 센다. 기존 3,200개 중 3,185개는 일부 한자 공유, 15개는 같은 표제어에 다른 읽기를 붙인 표시였다.

## 적용 기준

- 표제어 또는 같은 용법의 어떤 예문 정답과도 한자를 하나라도 공유하면 비교어에서 제외한다.
- 자·타동사, 사동·수동·활용·파생형, 같은 표기의 다른 읽기, 합성어의 일부 한자 공유를 포함한다.
- 편집 우선순위도 이 기준을 우회하지 않는다. 후보를 제외한 다음 기존 검토 후보 안에서 최대 2개를 선택한다.
- 안전한 후보가 없으면 빈 선택을 저장하고 비교어 줄을 생략한다. 한국어 뉘앙스 힌트는 유지한다.
- 자료 누락·버전 불일치의 기존 대비 경로에도 같은 기준을 적용한다.
- 가나가 일부 겹치는 별도 표현(では→それでは)은 유지한다.

전체 5,658용법의 ID·표기·읽기·뜻·기존 표시·제외 이유·최종 표시·추가 후보 제외 목록은 [전량 전후 기록](hint-answer-leakage-review.json)에 있다. 이 기록은 필터 적용 후의 화면만 확인해 원본의 위험한 후보를 놓치지 않도록 수정 전 선택 원본도 보관한다.

## 원본과 검토 이력

단어·용법·예문 원본, ID·버전·소속·순서와 기존 독립 승인 해시는 변경하지 않았다. 기존 비교 원문, 의미 검토 그룹, 최초 大切→大事 보완 기록과 선호 후보는 역사적 근거로 보존했다. 전체 용법의 화면 선택 자료를 재생성했으며, 새 독립 의미 승인을 주장하지 않는다. 비교어의 의미 관계는 기존 검토 후보에 근거한다.

## 재현과 검증

`npm run hint:audit -- --require-complete`로 검토 원장·원본·선택 자료의 일치와 미검토 그룹 0을 확인한다. `npm run hint:display-audit`는 전체 선택 원본과 대비 경로를 검사하며 정답 노출이 남으면 실패한다. 전체 후보별 결과는 `output/hints/review-audit.json`, 현재 공급/안전 비교어는 `output/hints/display-audit.json`에 생성된다.

회귀 검사는 전량 예문의 한자 비노출, 기존 대비 경로, 다른 읽기의 동형어, 자·타동사/사동형, 가나 표제어의 한자 정답, 빈 선택의 유지, 한국어 힌트만 남는 화면을 포함한다. 전체 빌드·테스트·콘텐츠/최종 선정 감사는 `npm run check:release`로 확인한다. 웹 게시 여부는 별도의 실제 배포 확인이 필요하다.

이번 실행에서 `check:release`의 빌드·54개 검사 파일/359개 검사·콘텐츠 감사·최종 선정 감사가 모두 통과했다. 힌트 검토 감사의 미검토 그룹은 0, 화면 선택 원본 전량 감사의 정답 노출은 0이다. 단어·용법·예문 원본과 기존 승인 해시의 보존도 기존 감사로 확인했다.
