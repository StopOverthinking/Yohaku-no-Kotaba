# 통합 유의어 연결 검수 C

`output/synonym-groups-1.json`의 346묶음(0–345)을 모두 읽고, 각 묶음에 속한 항목의 실제 일본어 예문 두 개와 힌트·구별 설명을 서로 대조했다. 스냅샷의 ID로 최신 `pilot.tsv`, `author-a.tsv`, `author-b.tsv`, `author-c.tsv`를 조회했다. 같은 표제어의 복수 ID도 함께 읽었다. 기존 개별 문법 검수를 반복하는 대신, 유의어의 적용 범위와 교체 가능성, 문체·결합 차이를 집중 검토했다.

검수 완료: **346 / 346묶음**. 원고 직접 수정: **0행**. 아래 **6개 ID의 변경을 통합 담당자가 반영했으며 최신 TSV에서 모두 확인했다**. 일본어 예문 변경은 1개이며 나머지는 한국어 설명의 과도한 배제를 줄이는 수정이다. 검수하지 않은 묶음이나 뜻을 결정하지 못한 항목은 없다.

`integration-corrections.json`의 30행 수정도 확인했다. 특히 `AbsoluteVerb_325`의 ‘여럿’ 제한은 최신 원고에서 이미 제거되어 추가 변경 대상에서 제외했다.

## 반영 완료한 변경

### 1. AbsoluteVerb_107 — しゃがむ / 座る (묶음 19)

현재 구별 설명은 ‘앉는 일 전체 중’이라고 하여 쪼그리는 자세를 일본어의 일반적인 착석과 같은 범주로만 설명한다. 두 예문은 엉덩이를 의자나 바닥에 내려놓는 것보다 무릎을 굽혀 몸을 낮추는 자세가 구체적인 단서다.

- `distinction`: `座る는 엉덩이를 의자나 바닥 등에 대고 앉는 데 흔히 쓰고, しゃがむ는 무릎을 굽혀 몸을 낮추는 자세를 나타낸다.`

### 2. AbsoluteVerb_92 — 触る / 撫でる (묶음 223·224·322)

‘지속적으로 쓸어 주는 것이 아니라’는 넓은 접촉 동사에서 쓰다듬는 접촉을 배제하는 인상을 준다. 실제 차이는 접촉 여부와 접촉 방식의 구체성이다. 구별 설명은 이미 이 관계에 맞으므로 힌트만 바꾸면 된다.

- `hint`: `손을 대어 접촉하는 행동이에요. 부드럽게 쓸어 주는 방식까지 특정하지는 않아요.`

### 3. AbsoluteVerb_171 — 死ぬ / 枯れる (묶음 53·244)

‘사람과 동물의 생명이 끝남’만을 대비하면 식물에는 죽음을 나타내는 말을 쓸 수 없다는 인상을 준다. 대표 예문은 그대로 유지하되, 식물에도 쓸 수 있는 일반적인 생명 종료와 식물이 말라 생기를 잃는 변화의 차이로 설명한다.

- `distinction`: `死ぬ는 사람·동물을 비롯한 생물의 생명이 끝남을 넓게 말하고 식물에도 쓸 수 있다. 枯れる는 식물이 말라 생기를 잃는 변화에 특히 자연스럽다.`

### 4. AbsoluteVerb_305 — 潜る / 泳ぐ (묶음 265)

‘물 위에서 헤엄치는 것과 달라요’는 헤엄치기를 수면에 한정하는 듯하다. 같은 묶음의 泳ぐ는 물속에서 헤엄치는 거북이 예문을 갖고 있다. 두 표현의 차이는 수면 위·아래의 이분법이 아니라 이동 방식과 수면 아래로 들어가는 동작의 초점이다.

- `hint`: `몸을 수면 아래로 넣어 들어가요. 헤엄치는 이동 방식보다 잠수하는 동작에 초점이 있어요.`

### 5. AbsoluteVerb_240 — 聞こえる / 聞く (묶음 309)

현재 구별 설명의 ‘의도적으로 듣는 행동’은 聞く의 모든 쓰임을 의도적 청취로 읽게 할 수 있다. 원래 힌트의 ‘일부러 귀 기울이지 않아도’는 적절하다. 행동 주체와 소리가 들리는 상태의 차이로만 설명하면 충분하다.

- `distinction`: `聞く는 듣는 사람이 소리를 받아들이는 행위에, 聞こえる는 소리가 귀에 닿아 들리는 상태에 초점을 둔다. 듣는 행위가 언제나 의도적인 것은 아니다.`

### 6. AbsoluteVerb_582 — 解く / 解ける (묶음 321)

두 항목의 예문 2가 모두 ‘この謎が[解ければ]、…分かる’이다. 解く의 가능형과 解ける의 조건형이 실제로 겹치므로 독음·형태만으로 구별되지 않는다. 이것을 오문이라고 판단하지는 않는다. 다만 두 연결 항목에 거의 같은 조건문을 두어 ‘푸는 행동 / 풀리는 결과’를 억지로 나누기보다, 解く 쪽의 두 번째 예문을 명시적인 타동사 동작으로 바꾸면 학습 근거가 분명해지고 장면 중복도 줄어든다.

- `sentence2`: `宿題は、答えを見ずに自分で[解いて/といて]みよう。`
- `translation2`: `숙제는 답을 보지 않고 스스로 [풀어] 보자.`

## 유지한 판단

- 光る/輝く, 住む/暮らす, 余る/残る, 励む/頑張る, 大切/重要, 比べる/比較する, 浮かぶ/浮く 등의 예문은 교체 가능한 곳이 있지만, 설명이 초점·범위·문체 차이를 제시하거나 겹침을 인정하므로 강제로 유일 정답 문맥을 만들지 않았다.
- 비교 연결은 표제어 단위이므로, 대표용법이 다른 いただく/召し上がる, 吹く/弾く, 書く/著す 등의 묶음에 서로 다른 대표용법이 나온다는 사실 자체를 오류로 처리하지 않았다.
- 자동사·타동사의 구별은 원인이 저절로 생기는지 또는 행위가 고의인지로 판정하지 않았다. 통합 담당자가 이미 고친 설명을 재수정하지 않았다.
