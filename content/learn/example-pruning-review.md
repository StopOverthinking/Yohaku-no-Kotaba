## 판단 기준과 범위

전체 복수 예문의 기존 용법 설명과 번역 목표 표현을 대조했다. 다의어·의미 차이 후보는 문장 전체 번역을 추가 확인했다. 시제·활용·장면·대상만 다른 예문은 같은 그룹으로 묶고 기존 첫 예문을 대표로 유지했다. 어휘 의미, 관용적 용법, 화용 기능의 차이는 남겼다. 이번 정리는 기존 수록 의미의 중복 판단이며, 모든 일본어 문장의 신규 독립 교정이나 사전 전체 의미 검토를 수행했다는 뜻은 아니다.

- `飽きる`: 반복 경험으로 싫증이 난다는 동일 의미를 대표 예문으로 통합.
- `高い`: 공간적 높이 / 높은 가격을 각각 유지.
- `夢`: 수면 중의 꿈 / 장래 희망을 각각 유지.
- `適当`: 상황에 알맞음 / 성의 없이 대충함을 각각 유지.

190개 용법의 복수 의미 그룹을 유지했다. 이 중 60개 용법은 기존 예문을 모두 남겼고, 나머지는 각 의미 그룹의 중복만 줄였다. 상세 분류와 대표 ID는 [전체 판단 원장](example-pruning-review.json), 삭제 원문·대표 예문 연결·전후 해시는 [삭제 이력](example-pruning/2026-10-02-equivalent-examples.json)에 있다.

## 프로그램 처리

- 진행 세션, 대기·재시도 카드와 모든 되돌리기 기록의 정확한 예문 ID·버전을 대표 예문으로 연결한다. 새 문장의 정답과 힌트는 다시 가린다.
- 기존 숙련도, 점수, 복습 예정일, 삭제 예문의 노출 통계와 되돌리기용 프로필을 보존한다. 대표 예문을 이미 본 것으로 임의 집계하지 않는다.
- 복구는 기존 IndexedDB 단일 저장 절차를 사용한다. 저장 실패 시 원본을 유지하고, 재시도·재로딩 시 이중 이전하지 않는다. 기존 백업 형식을 유지하며 복원 후 같은 복구 절차를 사용한다.
- 생성기와 게시 검증은 삭제 이력으로 원래 승인된 콘텐츠를 검증하되 현재 수량은 실제 남은 데이터에서 센다. 기존 독립 검토 해시나 승인 파일을 재작성하지 않았다.
- 옛 원고의 재가져오기는 삭제 예문을 되살리지 않는다. 정리한 용법의 문구까지 바꾸는 후속 작업은 별도 콘텐츠 변경 이력이 필요하다.
- 후리가나 생성은 검증된 삭제 예문에 해당하는 과거 보정만 제외한다. 살아 있는 예문에 대한 기존 검증은 유지한다.
