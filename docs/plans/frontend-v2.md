# 프론트엔드 v2 개선 계획

작성 기준: 2026-10-24. 기존 프론트엔드(`index.html` → `src/`)는 그대로 두고, 새 화면 계층을 `v2/`에 따로 만들어 비교·시연한다. 이 문서는 현재 기능 계약을 대체하지 않는다.

## 고정 조건

- 콘텐츠·어휘 데이터는 수정하지 않는다: `content/`, `src/features/vocab/editor-data/`, 생성된 `src/features/vocab/data/`, 생성 스크립트, 감사 원장.
- `src/` 아래 기존 파일은 한 줄도 바꾸지 않는다. v2는 기존 스토어·엔진·선택 로직을 **읽기 전용으로 import**하고 화면(컴포넌트·CSS)만 새로 만든다.
- 학습 정책(v4 복습 일정, 점수, 세션 재학습, undo, IndexedDB 단일 트랜잭션 저장)과 백업 형식은 기존 모듈을 그대로 호출하므로 달라지지 않는다.
- 같은 출처(origin)에서 열면 v1·v2가 같은 학습 기록·설정·즐겨찾기를 공유한다. 두 탭을 동시에 쓰면 기존 revision 충돌 보호가 그대로 작동한다.
- 기존 빌드·테스트·Pages CI(`npm run build`, `npm test`, `check:release`)에 영향을 주지 않는다. v2는 별도 설정(`v2/vite.config.ts`)과 별도 산출물(`dist-v2/`)을 쓴다.
- 디자인 원칙(미니멀, 아이콘 중심, 설명 최소화, blur·filter·backdrop-filter·height 애니메이션 금지)을 유지한다.

## 정보 구조(IA)

- 모바일: 하단 탭 4개 `학습 · 단어 · 복습 · 설정`. 학습 세션 중에는 탭을 숨긴다.
- 데스크톱(≥ 900px): 같은 항목을 왼쪽 레일로.
- 라우터는 해시 라우터(`#/…`). 정적 호스팅·하위 경로·미리보기에서 404 대체 설정 없이 동작한다. 경로는 v1과 같게 유지: `#/`, `#/list`, `#/learn/session`, `#/learn/result`, `#/learn/review`, 추가로 `#/settings`. `#/learn`은 홈으로 이동.

## 디자인 시스템

- 색: 라이트 = 종이(`#F5F3EE`) + 먹(`#1B1B1A`), 다크 = 먹(`#121314`) + 한지(`#ECEAE4`). 강조 1종(藍 계열), 정답 강조(朱 계열), 앎(녹)·모름(주홍)만 의미색. 모두 CSS 변수, 기존 `data-theme`·테마 저장값을 그대로 사용.
- 형태: 반경 12/16/999, 선 1px, 그림자 없음(시트·다이얼로그만 약한 그림자).
- 글자: UI는 시스템 한글 산세리프, 일본어는 Hiragino/Noto Sans JP 계열. 크기 단계 12/14/16/20/28/40.
- 모션: 화면 진입 opacity + y 6px 160ms, 시트 transform 180ms, 스와이프는 transform만. `prefers-reduced-motion`에서 모두 제거. motion 라이브러리 미사용.
- 접근성: 모든 아이콘 버튼 `aria-label`, 포커스 링, 터치 타깃 44px 이상, 대비 4.5:1 이상 목표.

  vite.config.ts        # root=v2, base='./', @ → ../src, outDir ../dist-v2, port 5174

  src/
    main.tsx, App.tsx   # 셸(탭/레일), 해시 라우터, hydrate

## 실행

## 단계

1. **골격**(완료): 별도 진입점·설정·해시 라우터·토큰·셸.
2. **핵심 학습 흐름**(완료): 오늘(홈+설정) → 세션 → 결과, 앱 내부 파기 확인.
3. **보조 화면**(완료): 복습 목록, 단어 목록, 설정(테마·백업·출처).
4. **검증**(완료): v2 타입 검사·빌드, 모바일/데스크톱·라이트/다크 스크린샷, 기존 파일 해시 불변 확인.
5. **사용자 검토 후 결정할 것**
   - 실제 휴대폰·Safari에서 루비 배치, 하단 고정 버튼, 스와이프 체감 확인.
   - v2 화면 테스트(Testing Library) 추가 범위. 지금은 기존 `npm test`에 섞이지 않도록 넣지 않았다.
   - 전환 방식: (a) v2를 `/v2/`로 함께 게시해 병행 운영 → (b) 기본 진입점 교체 → (c) v1 화면 코드 제거. 교체 시 위키(`architecture.md`, `app-shell.md`, `design-rules.md`, 기능 문서) 갱신.

## 2026-10-24 전환

사용자 지시로 `frontend-v2` 브랜치를 만들고 루트 진입점(`index.html` → `v2/src/main.tsx`)을 v2로 교체했다. 2026-10-23 힌트 추가의 로컬 콘텐츠·코드 변경 9개 파일은 이 전환 커밋에 포함되지 않았으며, 아래 2026-10-26 통합에서 반영한다. v1 화면 코드와 테스트는 그대로 남아 있으며 `check:release` 범위도 바뀌지 않았다. 이 브랜치 푸시가 Pages 게시를 시작하도록 워크플로 트리거에 `frontend-v2`를 추가했다. 이후 `main`을 푸시하면 v1이 다시 게시되므로, v2 확정 시 `main`에 병합한다.

## 2026-10-26 로컬 힌트 통합

`origin/frontend-v2`의 새 화면·복습 수 계산 두 커밋 위에 `案内放送`·분리 용법의 `熱烈に` 선정, 근거 검증기·검사·생성 자료·관련 위키를 함께 반영했다. 로컬 변경 9개와 원격 변경 35개 파일의 경로 중복은 없었고, 브랜치 전환 전후 로컬 파일 해시가 모두 같았다. v2는 기존 `similarHintWords`를 사용하므로 별도 힌트 데이터나 화면 분기를 추가하지 않는다. 기존 ID·버전·승인 이력·저장 형식과 원격의 v2 진입점을 보존한다. 로컬 통합은 GitHub 푸시나 공개 게시 성공을 뜻하지 않는다.

- `npm run extract:vocab`, `npm run hint:audit -- --require-complete`, `npm run hint:display-audit`, `npm run typecheck:v2` 통과. 실제 5,874용법·예문의 표시 감사에서 `unsafeLabels: 0`이다.
- `npm run check:release` 통과: v2 기본 진입점 빌드, 58파일·402검사, 전체 콘텐츠·최종 선정 감사. 기존 큰 번들 경고는 남는다.
- 격리한 Chromium 세션의 390×844 화면에서 두 대상 용법을 실제 엔진으로 준비해 비교어의 정답 공개 전 표시, `H` 힌트 조작, 새로고침 후 세션·힌트 복원, 정답 공개와 가로 넘침 없음을 확인했다. 사용자 브라우저의 학습 기록을 사용하지 않았으며 실제 휴대폰·Safari 검증은 포함하지 않는다.

## 2026-10-26 main 통합

후리가나 겹침 수정까지 포함한 `frontend-v2`를 `main`에 fast-forward로 통합해 (b) 기본 진입점 교체를 `main`에 반영했다. `npm run check:release` 통과 후 푸시했고, `frontend-v2` 브랜치와 워크플로 트리거를 제거했다. (c) v1 화면 코드 제거는 남아 있다.

## 남은 위험

- 목록은 기존의 세밀한 터치·스크롤 위치 복원 최적화를 모두 옮기지 않았다(스크롤 위치는 세션 단위 복원만).
- QR 스캔은 기존과 같이 `BarcodeDetector`를 지원하는 브라우저에서만 동작한다.
- 같은 브라우저에서 v1·v2를 번갈아 쓰면 기록은 공유되지만, 한쪽 탭에서 저장한 뒤 다른 탭은 새로고침이 필요하다(기존 충돌 보호 동작).
