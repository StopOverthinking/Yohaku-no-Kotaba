# Learn Mode

추천·판정·복습 목록은 가벼운 용법 인덱스를 사용하고, 학습 화면은 현재 카드의 예문 묶음만 지연 로딩한다. 로딩 중에는 정답 공개·판정을 차단하며 이전 카드의 비동기 응답을 무시한다. 다운로드 실패에도 저장된 세션은 유지한다. 다시 불러오기는 브라우저의 실패한 모듈 캐시를 새로고침으로 초기화한 뒤 같은 카드를 복원한다.

## 목적과 진입점

한자를 보기 전에 문맥으로 회상하는 문장 빈칸 학습이다. 설정 `/learn`, 진행 `/learn/session`, 결과 `/learn/result`를 유지한다. 비교형은 제외한다.

## 콘텐츠와 전환 조건

- 대표 의미·뉘앙스마다 검수 예문 1개를 사용한다. 2026-10-02부터 기존 2·3개 예문도 의미별로 검토하여 같은 의미의 장면·대상·활용 차이는 대표 하나로 통합한다. 실제 의미·관용적 쓰임·화용 기능이 다르면 복수 예문을 유지한다.
- 전체 신규 어휘의 첫 출제와 서로 다른 날짜의 보유 예문 순환(1개이면 같은 예문 재사용)을 `jlptPilot.test.ts`에서 확인한다.

- 원본은 `vocab/editor-data/learnContent.json`, 생성된 런타임 데이터는 `vocab/data/learnContentIndex.ts`와 `learnContentShards/`다. 전체 `learnContent.ts`는 편집·검사 용도로 유지한다.
- 단어에 용법을 연결하고, 용법마다 검수 예문을 최소 1개 제공한다.
- 단어 검수, 유의어 검수, 다양성 검수와 예문별 `reviewed` 상태가 모두 필요하다.
- 모든 기본·주제형 단어가 준비되고 생성 시 전체 구조 검증에 오류가 없을 때 새 세션을 문장 방식으로 전환한다. 준비되지 않은 콘텐츠는 시작을 차단하고 안내한다.
- 문장 세션 안에서 예문이 없는 항목을 단어 카드로 대체하지 않는다. 내려받은 묶음도 ID·버전·난도·검토 상태를 인덱스와 대조하고 본문 구조를 검증한 뒤 표시한다.
- 문장 학습만 제공한다. 예전 단어 카드 엔진과 기타 학습 모드는 제거했다. 이미 저장된 문장 학습 기록은 보존한다.

## 화면과 판정

1. 목표 활용형 전체를 일정 폭 빈칸으로 가린 일본어 문장과 전체 한국어 번역을 표시한다. 목표어 앞뒤 문장의 한자에는 후리가나를 붙이며, 본문과 다른 약간 옅은 테마 색을 사용한다.
2. 번역의 목표 표현은 가볍게 강조한다.
3. 전구 아이콘은 한국어 뉘앙스 힌트와 `비슷한 단어: 大事`처럼 혼동 표현의 일본어 표기를 함께 표시한다. 기존 `confusions`도 후보로 포함해 현재 용법의 편집 우선순위, 한국어 뜻의 겹침, 기존 대비, 사전 상용어·빈도 근거 순으로 선택한다. 버전이 일치하는 `hintConfusions` 선택 자료를 사용하고 자료가 없거나 버전이 다르면 기존 대비 표현을 사용한다. 빈 값·중복·현재 표제어/정답/읽기를 제외한 뒤 **최대 2개**만 ` · `로 구분해 표시한다. 편집자가 1개만 지정한 용법에 기존 대비를 덧붙여 2개로 늘리지 않는다. 전체 비교 목록을 펼치는 버튼은 두지 않는다. 같은 한자의 다른 읽기는 `止める（とめる）`처럼 구분하며 자기 읽기를 덧붙인 정답은 표시하지 않는다. 비교 대상이 없으면 라벨도 생략한다. 차이 설명 원문은 정답을 포함할 수 있어 화면에 추가하지 않는다. 힌트를 접으면 두 줄 모두 숨기며 정답 공개와 독립적이다.
4. 카드 전체 표면을 누르면 문장 속 정답, 활용형 읽기, 기본형과 읽기를 표시한다. 여백·번역·상태 배지·도구 사이 여백도 공개 영역이다. 이전 카드·힌트·즐겨찾기·글자 크기 버튼은 별도로 동작한다.
5. 앎/모름은 사용자 판단이다. 공개나 힌트 사용 여부에 따른 제한·감점은 없다.
6. 왼쪽/오른쪽 스와이프와 방향키는 앎/모름, 스페이스는 공개다. 공개 버튼에 포커스가 있으면 Enter도 사용할 수 있다. 더블 클릭·키 반복·스와이프 뒤 합성 클릭으로 두 문제가 처리되거나 다음 정답이 공개되지 않게 한다.

카드 안 모퉁이의 별도 상태 배지는 현재 용법 버전의 프로필이 없으면 `새 단어`, 있으면 마지막 학습일부터 현지 달력 날짜로 계산한 `n일 전`을 표시한다. 당일 재학습은 `0일 전`이다. 저장 필드를 추가하지 않고 복원된 프로필에서 계산하므로 되돌리기와 새로고침도 같은 상태를 표시한다.

후리가나는 빌드 전용 사전으로 `before`와 `after`만 분석해 현재 5,874개 예문의 지연 로딩 묶음에 생성한다. 브라우저에 사전·분석기를 포함하지 않으며 원고·용법/예문 버전·검토 해시는 바꾸지 않는다. 수사·조수사 읽기 규칙과 원문 일치를 검증한 문맥별 보정을 사용한다. 자동 생성은 전량 언어 검수의 대체가 아니며 읽기 위험 후보와 다의어 문맥을 별도로 검토한다.

정답 공개 전 목표어 자체와 읽기는 숨긴 DOM에도 넣지 않는다. 사용자가 연 힌트의 별도 비교 표현에는 같은 글자가 일부 포함될 수 있다(では의 비교 단어 それでは 등). 카드 전환에 blur, filter, height 애니메이션을 사용하지 않는다.

## 설정과 후보 선택

- 전체 자동 추천이 기본이다. 단어장, 즐겨찾기, 일반 범위, 여러 필수 포함 범위를 유지한다.
- 범위 입력의 빈 문자열 편집과 blur 복구, 필수 범위 겹침 제거, 필수 개수 이상의 학습 개수 보정을 유지한다.
- 필수 범위는 현재 단어장·즐겨찾기 조건의 목록 순번을 사용하며 일반 범위 밖이어도 포함한다.
- 기본 학습 개수 10개. 재학습은 이 개수와 별도다.
- 선택한 단어장·즐겨찾기·일반 및 필수 범위에서 오늘까지 복습일이 도래한 단어가 있으면 개수 설정 근처에 `오늘 복습해야 하는 n개의 단어가 있어요`를 표시한다. 현재 용법 버전만 포함하고 같은 단어의 복수 용법·별칭은 대표 단어 ID로 한 번만 센다. 0개일 때는 표시하지 않는다.
- 오늘 학습 가능한 필수 단어 → 복습 예정일 도래 → 수준에 맞는 새 항목 순서로 매 응답 후 다음 항목을 선택한다. 예정일 전·완료·사용자 삭제 단어는 필수 범위에서도 제외하며 실제 가능한 필수 개수와 최대 학습 개수를 표시한다.
- 연체일이 오래된 항목부터, 동률이면 실패가 많은 항목부터 복습한다.
- 세션별 무작위 순서로 동일 추천 점수의 동률을 해소한다.
- 다음 카드 선택은 우선순위·예정일·실패·난도 거리·동률 순서를 유지하면서 전체 정렬 대신 한 번 순회해 최선 후보만 구한다.
- 첫 라운드에서 같은 단어를 중복 선택하지 않는다.
- 모든 학습 범위에서 예정일 전 단어를 제외한다. 단어장·즐겨찾기·필수 범위와 옛 `allowEarly: true`도 이 규칙을 우회하지 않는다. 같은 단어의 다른 용법이 미학습이어도 현재 용법에 대기 중인 복습이 있으면 단어 전체를 기다린다. 이미 오늘 학습한 단어는 새 세션에 넣지 않는다. 단, 같은 세션 안의 모름 재학습은 유지한다.
- 옛 진행 세션·undo에 조기 학습 카드나 삭제한 단어가 있으면 저장 후 해당 카드를 건너뛰고 가능한 다음 카드·재학습으로 이어간다. 가능한 카드가 없으면 세션을 닫으며 기존 프로필·점수를 유지한다.
- 후보가 없으면 다음 복습일을 설정에 표시한다. 범위 밖의 항목으로 채우지 않는다.

## 수준 측정

처음 보는 서로 다른 20개 단어의 자기평가를 누적한다. 학습 기록이 없는 사용자는 N5~N4 수준으로 가정해 **16점**으로 시작한다. 현재 검토 예문의 N5 중앙값 14와 N4 중앙값 18 사이를 선택한 고정 초기값(`RECOMMENDATION_POLICY.initialLevel`)이며, 전체 콘텐츠가 늘거나 첫 단어장·범위를 바꿔도 달라지지 않는다. 초기 20단어는 0개부터 실제 응답으로 누적하고, 이미 측정하거나 학습한 기록이 있으면 기존 점수·프로필·복습일을 유지한다. 예전 중앙값만 저장된 미학습 상태도 첫 세션 시작 시 16점으로 맞춘다.

`p = 1 / (1 + exp((difficulty - level) / 8))`

`level += K * (known - p)` (`known`: 앎=1, 모름=0)

처음 20개는 K=8, 이후 K=2. 초기 새 문제는 예상 앎 확률 50%, 이후 75%에 가까운 문제를 고른다. 같은 용법은 하루 한 번만 수준에 반영한다. 속도와 힌트로 감점하지 않으며 JLPT 등급으로 표현하지 않는다.

## 재학습과 복습일

- 모름 항목만 다음 라운드에서 같은 예문으로 다시 낸다. 전부 앎이 될 때까지 횟수 제한 없이 반복한다.
- 다음 날짜에는 예문이 여러 개이면 직전에 본 예문을 피하고 노출이 적은 예문을 우선한다. 예문이 1개이면 그 예문으로 복습한다.
- 처음 보고 바로 앎: 3일 → 7일 → 30일 → 90일 간격으로 복습한다. 90일 뒤의 예정 복습도 맞히면 `mastered: true`로 완료하고 복습 목록·자동 추천·오늘 복습 수·다음 복습일에서 제외한다. 90일을 예약하는 시점에는 완료하지 않는다.
- 오답은 이전의 정답/오답 횟수·단계·완료 상태와 관계없이 단계 0, 다음 날, 1회 오답 흐름으로 재시작한다. 누적 오답으로 간격을 추가 단축하지 않는다.
- 오답 흐름은 **1·2·3·5·8·14·21·36·48·72·96·120일**이다. 오답 다음 날부터 시작하고 예정일마다 맞히면 다음 간격으로 이동한다. 마지막 120일을 예약할 때는 완료하지 않으며, 그 예정 복습도 맞히면 `mastered: true`로 완료한다. 두 흐름 모두 완료 단어를 복습 목록·학습 세션·오늘 복습 수·다음 복습일에서 제외한다.
- 같은 용법은 같은 날의 첫 판정만 점수·실패 횟수·실패 날짜·복습 단계·예정일·완료 상태에 반영한다. 첫 정답 뒤 당일 오답도, 첫 오답 뒤 당일 정답도 이 값을 바꾸지 않는다. 다른 세션·새로고침에도 같은 규칙이다. 시도/노출·힌트 횟수와 재학습 큐는 실제 조작대로 유지한다.
- 예정일 전의 첫 라운드 판정은 엔진에서도 거부한다. 완료 단어의 직접 조기 연습 예외는 제거했다.
- 날짜는 현지 달력 날짜이며 연체 복습은 실제 복습일부터 다음 간격을 계산한다.

## 저장과 되돌리기

- `contextStore`는 IndexedDB에 바뀐 프로필과 세션·undo를 함께 저장한 후 화면을 진행한다. 기존 v2 기록은 원본을 보존하면서 이전하며 백업 형식은 유지한다.
- 저장 오류 시 현재 카드를 유지하며 동일 조작으로 재시도할 수 있다.
- 현재 예문, 공개, 힌트 표시·사용 여부, 대기열, 연속 되돌리기 정보를 복원한다.
- 되돌리기는 용법 프로필, 수준, 예문 선택과 큐를 함께 복원한다.
- 다른 탭이나 백업 복원으로 저장값이 달라지면 덮어쓰지 않고 새로고침을 안내한다.
- 완료 결과는 메모리만 사용하고 진행 세션·undo 기록은 지운다. 숙련도·일정은 유지한다.
- 완료 화면의 홈 이동은 결과를 비운 뒤에도 목적지를 유지한다. 퇴장 애니메이션 동안 남아 있는 결과 화면이 학습 설정으로 다시 보내지 않도록 한다.
- 세션 파기도 이미 판정한 숙련도는 유지한다.
- 용법/예문 버전이 달라진 진행 카드는 답을 처리하지 않고 새 세션 시작을 안내한다. 문장만 정정한 예문 버전 증가는 용법 숙련도와 복습 예정일을 바꾸지 않는다.
- 삭제 이력에서 같은 의미의 대체 예문을 명시한 경우에는 hydrate에서 현재 카드·대기열·재학습·undo의 카드 참조를 대체한다. 새 예문은 정답과 힌트를 다시 가리고, 프로필·복습일·점수·과거 예문별 노출 기록은 유지한다. 저장에 성공해야 화면에 반영된다. 기록되지 않은 삭제나 다른 버전은 자동으로 추측해서 바꾸지 않는다.
- 기존 핵심 뜻을 보존한 설명 정정은 용법 ID/버전을 유지한다. 추가된 별도 용법은 새 프로필로 학습하며 기존 용법 예정일·숙련도·예문 노출은 그대로다. 같은 단어에 새 용법이 생겨도 초기 수준 측정의 단어 수를 중복 가산하지 않는다.

## 구현과 검증

`contextReviewPolicy`는 정책 상수·현지 날짜·복습 간격·하루 판정·완료 상태 계산을 담당하는 순수 모듈이다. `contextEligibility`는 날짜와 삭제에 따른 단어 출제 자격, `contextEngine`은 추천·점수·세션 진행·undo를 조립한다. `contextPersistence`는 엔진에 의존하지 않고 정책 v1~v4를 검증·이전한다. `contextStore`는 저장과 중복 판정 방지, `ContextSessionPage`는 카드 조작이다.

정책 날짜·입력 프로필 불변, 엔진 반복·undo, 저장 실패·새로고침·백업, 공개 전 DOM 비노출, 힌트 독립성, 범위·필수 단어를 자동 검증한다. 실제 브라우저에서 좁은 화면과 키보드·포인터 조작을 확인한다.

## 점수 표시와 복습 목록

- 설정은 내부 추천 수준을 소수점 첫째 자리까지 `학습 점수`로 표시한다. 만점·합격선·JLPT 등급이 없으며 점수 자체를 0~100으로 제한하지 않는다.
- 처음 20단어 측정 진행량, 가장 최근 완료 세션의 전후 점수와 증감을 표시한다. 완료 화면에도 같은 값을 표시한다. 저장이 실패한 판정은 반영하지 않고 undo 후의 순변화만 집계한다.
- `/learn/review`는 현재 용법 버전의 프로필 중 완료·사용자 삭제를 제외한 항목을 모두 표시한다. 예정일 오름차순, 동률은 실패 횟수 내림차순이다. 표기·읽기·뜻·예정일·간격과 검색을 제공한다. 90일·120일의 마지막 복습 대기 중에도 목록에 남는다.
- 각 행의 휴지통은 단어 전체의 삭제 확인 팝업을 연다. `정말 삭제할까요?`와 해당 단어, 취소·삭제를 표시하며 취소에 초기 포커스를 둔다. Escape·바깥 클릭은 취소다. 저장 중에는 닫기·중복 삭제를 막고 실패하면 팝업 안에서 재시도한다. 네이티브 모달 dialog의 포커스 제한과 단색 backdrop을 사용하며 blur·filter를 추가하지 않는다.
- 확인 삭제는 프로필을 지우지 않고 대표 단어 ID를 `excludedWordIds`에 저장한다. 같은 단어의 모든 용법·별칭을 복습 목록·오늘 복습 수·다음 복습일·전체 학습 범위에서 제외한다. 기존 점수·프로필·예문 기록은 보존하며 새로고침·백업·undo가 제외를 되돌리지 않는다.
- 설정의 접힌 안내에 두 흐름, 하루 첫 판정, 오답 초기화, 완료·직접 연습 규칙을 설명한다.
- 기존 예약일은 보존한다. 정책 변경 직후 표시 간격은 현재 계산 기준이며 과거에 예약된 날짜의 간격과 다를 수 있다.

2026-10-05 정책 v4: 오답은 새 12단계 인덱스를 사용한다. v1~v3의 오답 프로필·undo는 옛 1회 오답 보정 간격 이하의 가장 큰 새 간격 단계로 이동하며 예약일·횟수는 보존한다. 옛 120·144일 간격은 새 최종 120일 단계가 되며 현재 예약된 복습을 맞힌 뒤 완료한다. 오답 없는 기존 단계는 원래 15단계 인덱스를 유지한다(v1만 같은 기본 일수로 변환). 별칭 이전의 원본 보관 프로필은 역사적 값으로 변경하지 않는다. IndexedDB의 정책 이전은 헤더와 전체 활성 프로필·undo를 한 트랜잭션에 저장하고 실패하면 원본을 유지한다. 재로드로 단계를 중복 변환하지 않는다.

## 동일 용법 연결과 학습 범위

독립 의미 검토와 원본 해시 검사를 통과한 연결 그룹만 새 세션 후보·필수 단어·최대 개수·다음 복습일에서 대표 단어로 중복 제거한다. 기존 단어장의 순번과 단어 ID는 유지한다. 기존 단어장에서 선택해도 대표 용법의 기록을 이어 쓰며 두 단어장을 함께 선택해도 같은 용법을 중복 출제하지 않는다. 진행 중인 옛 세션은 원래 카드와 undo로 완료한 뒤 연결한다. 이전 원본은 v3 백업에 보존하며 자세한 저장 규칙은 `storage-and-share.md`를 따른다.
