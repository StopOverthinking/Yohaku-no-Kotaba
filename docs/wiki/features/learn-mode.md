# Learn Mode

## 목적과 진입점

한자를 보기 전에 문맥으로 회상하는 문장 빈칸 학습이다. 설정 `/learn`, 진행 `/learn/session`, 결과 `/learn/result`를 유지한다. 비교형은 제외한다.

## 콘텐츠와 전환 조건

- 원본은 `vocab/editor-data/learnContent.json`, 생성된 런타임 데이터는 `vocab/data/learnContent.ts`다.
- 단어에 용법을 연결하고, 용법마다 서로 다른 예문을 최소 2개 제공한다.
- 단어 검수, 유의어 검수, 다양성 검수와 예문별 `reviewed` 상태가 모두 필요하다.
- 모든 기본·주제형 단어가 준비되고 구조 검증에 오류가 없을 때 새 세션을 문장 방식으로 전환한다. 준비 전에는 기존 일반학습을 유지한다.
- 문장 세션 안에서 예문이 없는 항목을 단어 카드로 대체하지 않는다.
- 과거 세션은 기존 엔진으로 완료할 수 있다. 과거 단어 카드 응답에서 숙련도를 추정해 만들지 않는다.

## 화면과 판정

1. 목표 활용형 전체를 일정 폭 빈칸으로 가린 일본어 문장과 전체 한국어 번역을 표시한다.
2. 번역의 목표 표현은 가볍게 강조한다.
3. 전구 아이콘은 한국어 뉘앙스 힌트만 표시한다. 정답 공개와 독립적이다.
4. 카드를 누르면 문장 속 정답, 활용형 읽기, 기본형과 읽기를 표시한다.
5. 앎/모름은 사용자 판단이다. 공개나 힌트 사용 여부에 따른 제한·감점은 없다.
6. 왼쪽/오른쪽 스와이프와 방향키는 앎/모름, 스페이스는 공개다. 더블 클릭과 키 반복으로 두 문제가 동시에 처리되지 않게 한다.

정답 공개 전 목표 표기와 읽기는 숨긴 DOM에도 넣지 않는다. 카드 전환에 blur, filter, height 애니메이션을 사용하지 않는다.

## 설정과 후보 선택

- 전체 자동 추천이 기본이다. 단어장, 즐겨찾기, 시험 오답, 일반 범위, 여러 필수 포함 범위를 유지한다.
- 범위 입력의 빈 문자열 편집과 blur 복구, 필수 범위 겹침 제거, 필수 개수 이상의 학습 개수 보정을 유지한다.
- 필수 범위는 현재 단어장·즐겨찾기 조건의 목록 순번을 사용하며 일반 범위 밖이어도 포함한다.
- 기본 학습 개수 10개. 재학습은 이 개수와 별도다.
- 필수 단어 → 복습 예정일 도래 → 수준에 맞는 새 항목 순서로 매 응답 후 다음 항목을 선택한다.
- 연체일이 오래된 항목부터, 동률이면 실패가 많은 항목부터 복습한다.
- 세션별 무작위 순서로 동일 추천 점수의 동률을 해소한다.
- 첫 라운드에서 같은 단어를 중복 선택하지 않는다.
- 자동 추천에는 아직 복습일이 오지 않은 항목을 넣지 않는다. 지정 범위·단어장에서는 조기 연습할 수 있다.
- 후보가 없으면 다음 복습일을 설정에 표시한다. 범위 밖의 항목으로 채우지 않는다.

## 수준 측정

처음 보는 서로 다른 20개 단어의 자기평가를 누적한다. 초기값은 예문 난도 중앙값이다.

`p = 1 / (1 + exp((difficulty - level) / 8))`

`level += K * (known - p)` (`known`: 앎=1, 모름=0)

처음 20개는 K=8, 이후 K=2. 초기 새 문제는 예상 앎 확률 50%, 이후 75%에 가까운 문제를 고른다. 같은 용법은 하루 한 번만 수준에 반영한다. 속도와 힌트로 감점하지 않으며 JLPT 등급으로 표현하지 않는다.

## 재학습과 복습일

- 모름 항목만 다음 라운드에서 같은 예문으로 다시 낸다. 전부 앎이 될 때까지 횟수 제한 없이 반복한다.
- 다음 날짜에는 직전에 본 예문을 피하고, 노출이 적은 예문을 우선한다.
- 처음 앎: 다음 날. 예정된 복습을 바로 앎: 1·3·7·14·30·60·120·180일 단계.
- 실제 간격은 `max(1, round(기본 간격 / (1 + .25 * min(실패 날짜 수, 4))))`다.
- 모름은 단계 0과 다음 날로 재설정한다. 당일 재학습 성공은 이를 늘리지 않는다.
- 같은 날의 여러 세션도 단계 상승은 최대 한 번, 실패 날짜 증가는 한 번이다. 모름 횟수는 매번 센다.
- 조기 연습 앎은 기존 예정일 유지, 모름은 다음 날이다.
- 날짜는 현지 달력 날짜이며 연체 복습은 실제 복습일부터 다음 간격을 계산한다.

## 저장과 되돌리기

- `contextStore`는 상태 전체를 새 키 `jsp-react:context-learn-v2`에 먼저 저장한 후 화면을 진행한다.
- 저장 오류 시 현재 카드를 유지하며 동일 조작으로 재시도할 수 있다.
- 현재 예문, 공개, 힌트 표시·사용 여부, 대기열, 연속 되돌리기 정보를 복원한다.
- 되돌리기는 용법 프로필, 수준, 예문 선택과 큐를 함께 복원한다.
- 다른 탭이나 백업 복원으로 저장값이 달라지면 덮어쓰지 않고 새로고침을 안내한다.
- 완료 결과는 메모리만 사용하고 진행 세션·undo 기록은 지운다. 숙련도·일정은 유지한다.
- 세션 파기도 이미 판정한 숙련도는 유지한다.
- 용법/예문 버전이 달라진 진행 카드는 답을 처리하지 않고 새 세션 시작을 안내한다.

## 구현과 검증

`contextEngine`은 순수 추천·일정 계산, `contextStore`는 저장과 중복 판정 방지, `ContextSessionPage`는 카드 조작이다. 예전 `learnSessionStore`는 레거시 진행 세션만 담당한다.

엔진 날짜·반복·undo, 저장 실패·새로고침·백업, 공개 전 DOM 비노출, 힌트 독립성, 범위·필수 단어, 예문 xlsx 왕복을 자동 검증한다. 실제 브라우저에서 좁은 화면과 키보드·포인터 조작을 확인한다.
