# Editor

## 목적

단어장 원본 데이터를 데스크톱 표 편집 방식으로 관리하는 별도 앱이다.

## 진입점

- 라우트: `/editor`
- 셸: `src/features/editor/EditorScreen.tsx`
- 본문: `src/features/editor/WordbookEditorPage.tsx`

## 전제

- 모바일 비대응
- 넓은 고정형 레이아웃 우선
- 선택 상태와 주요 조작은 표에서 바로 보여야 함

## 편집 모드

- `basic`
- `theme`
- `compare`

각 모드는 좌측 세트 목록과 중앙 표 편집 화면을 공유하되, 행 구조가 다르다.

## 편집 대상

- 기본 세트와 단어
- 주제형 세트, 토픽, 단어
- 비교형 세트, 쌍, 설명

## 핵심 상호작용

- 세트 추가/삭제/정렬
- 단어 추가/복제/삭제/정렬
- 주제 토픽 추가/삭제
- 비교형 쌍 추가/삭제
- 셀 직접 편집
- 검색
- xlsx 양식 다운로드/업로드
- 워크스페이스 디렉터리 저장

## 내부 구조

- 초기 snapshot은 `editorData.ts`에서 로드
- 수정은 `snapshot` state에 누적
- validation issue가 하단 패널에 표시
- 저장 상태는 `idle | saving | saved | error`

## 파일 관련 역할

- `editorSerializer.ts`: 정규화, 검증, 빈 엔트리 생성, 출력 파일 생성
- `editorSpreadsheet.ts`: xlsx import/export
- `editorPersistence.ts`: 디렉터리 핸들, 권한, 파일 쓰기

## UI 규칙

- 상세 패널보다 표 직접 편집 우선
- 표 열은 짧은 라벨 사용
- 선택된 세트/행은 즉시 드러나야 함
- 설명 문구보다 구조와 위치로 의미 전달

## 수정 시 주의점

- 신규 N5~N1 단어장도 기존 기본형 표·예문 표·xlsx 경로를 사용한다. 외부 사전 기반의 고정 단어 ID는 정렬·저장 시 다시 매기지 않는다.
- 시범 원고 import는 에디터에서 바뀐 내용을 덮어쓰지 않는다. `content/jlpt/pilot/published.json`의 검토본과 달라진 데이터는 빌드 전 확충 감사에서 재검토를 요구한다.

- 에디터 데이터 구조를 바꾸면 런타임 데이터 생성 경로도 확인
- 워크스페이스 저장은 브라우저 권한 API와 연결돼 있어 수동 확인 필요

## 문장 예문 편집

기본·주제형 표에서 `단어 / 예문`을 전환한다. 예문은 페이지당 20개 용법으로 표시하여 전체 입력 칸을 동시에 렌더링하지 않는다. 별도 상세 패널 없이 용법, 힌트, 혼동 표현과 차이, 예문 앞/정답/뒤, 읽기, 번역·강조, 난도, 버전, 검수 상태를 직접 편집한다. 문장을 수정하면 해당 예문과 용법의 검수 상태를 해제한다.

xlsx에는 `learn_senses`, `learn_examples`, `learn_confusions` 시트를 추가한다. ID와 버전을 보존하며, 옛 xlsx에 이 시트들이 없으면 기존 예문을 유지한다. 단어 삭제 시 연결 예문을 제거한다. 저장 시 JSON과 런타임 TS를 함께 출력한다.

기본·주제형 단어는 정렬/삭제/저장 때문에 ID를 다시 매기지 않는다. 기존 접두사 정보는 보존하지만 기존 단어 ID를 바꾸는 용도로 사용하지 않는다. 정답·읽기 또는 용법 의미가 바뀌면 용법 버전을 올려 다른 숙련도로 처리한다. 번역·문장 교정은 예문 버전만 올리고 숙련도를 유지한다.

작성 중인 빈 초안도 파일과 xlsx에 저장할 수 있다. ID·연결·버전은 초안에서도 검사하며, 내용과 문맥 검사는 검수 완료로 표시한 예문에 적용한다. 초안은 출제되지 않는다.

같은 편집기에서 연속 저장할 때는 직전 저장 성공본을 버전 비교 기준으로 갱신한다. 의미·정답을 다시 바꾸어 저장하면 용법 버전도 다시 상승한다. 저장 실패 시 기준을 앞당기지 않는다.

수준별 기존 단어 참조를 위한 `membershipMode: explicit` 정규화/JSON·TS 저장 계약을 추가했다. 같은 단어 ID와 원본 소속을 보존하며 확정된 목록 뒤로 새 소유 단어를 추가한다. 표는 참조 목록 순서로 표시하고 순서 이동은 해당 목록만 바꾼다. 참조 행 삭제는 연결만 해제하며, 다른 단어장이 참조하는 원본 단어/단어장 삭제는 거부한다. 복제는 현재 단어장 소유의 새 ID로 만든다. xlsx는 숨겨진 membershipMode·원본 소속·원본 순서 정보를 보존하며, 가져오기에서 외부 ID 충돌과 소속 변경을 거부한다. 테스트용 참조 자료로 Chromium에서 행 이동·연결 해제·원본 삭제 보호·새 소유 복제·xlsx 재가져오기를 확인했다. 직접 다운로드의 OS 저장과 디렉터리 쓰기는 이번 확인 범위가 아니다. 첫 6개 고유 기존 ID를 승인 후 N3·N2 참조 목록에 연결했으며 이후에도 독립 승인된 항목만 추가한다.
