# Share Panel

## 목적

앱 전체 백업을 한 화면에서 제공한다.

## 진입점

- 홈 서브메뉴
- 컴포넌트: `src/features/share/SharePanel.tsx`

## 앱 섹션 액션

- 클립보드 복사
- 파일 저장
- QR 내보내기
- 클립보드 복원
- 파일 복원
- QR 복원

## QR 동작

- 큰 payload는 QR 한 장당 Base64 URL 텍스트 400자 이하로 분할
- 프레임 수를 늘리는 대신 QR 모듈을 크게 유지해 먼 거리에서도 전체 코드를 인식하기 쉽게 함
- 압축 후 64장 이하에서 SVG QR 생성; 초과하면 파일 저장 버튼 제공
- 여러 장이면 자동 재생
- 카메라 스캔은 브라우저 `BarcodeDetector`와 `getUserMedia` 사용

## 복원 흐름

- JSON 파싱
- 현재 envelope와 숫자 v1·버전 없는 옛 백업을 검증한다. 미지원 백업/학습/복습 정책 버전이나 손상된 학습 기록이면 확인·복원 전에 전체 가져오기를 거부한다.
- 확인 모달
- 복원 전 설정을 DB에 기록하고 학습 쓰기를 잠금
- 설정 교체 후 새 학습 상태와 복원 기록 제거를 한 DB 트랜잭션에서 확정
- 중간 실패·중단 시 이전 설정 복구
- 페이지 새로고침

미지원 버전은 지원하지 않는 종류와 기존 학습·설정 보존을 알리고 백업을 만든 앱 버전 또는 다른 백업 선택을 안내한다. 파일은 다시 선택할 수 있고, 수동 붙여넣기는 팝업 안에 오류를 표시하여 내용을 바꾸거나 취소할 수 있다. QR은 기존 다시/닫기 조작을 사용한다. 호환되지 않는 학습 기록을 버리고 설정만 가져오거나 현재 데이터를 초기화하지 않는다.

## UI 규칙

- 레이블은 짧게
- 버튼 의미는 아이콘 중심으로 바로 보이게
- 긴 설명은 확인 모달에서만 사용

## 수정 시 주의점

- 제거된 기능의 레거시 키가 앱 백업에 다시 섞이지 않게 한다.
- QR 복원은 앱 백업 포맷만 처리한다.

내보내기는 복원 잠금 아래에서 설정과 최신 학습 DB 스냅샷을 읽는다. 이전 완료 표시는 학습 데이터로 내보내지 않으며 기존 v2 백업을 계속 읽는다.
