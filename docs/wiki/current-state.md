## 학습 카드 조작과 상태 표시

- 카드 전체의 여백·문장·번역·모퉁이 배지로 정답을 공개한다. 내부 도구 버튼은 각각 독립적으로 동작하며 스와이프 뒤 클릭으로 다음 카드의 정답이 공개되지 않는다.
- 목표어 앞뒤 문장에 본문과 다른 조금 옅은 색의 후리가나를 표시한다. 현재 5,874예문의 원고·버전·삭제 이력은 보존하고 빌드에서 지연 로딩 묶음에 발음을 생성한다. 한자 읽기 누락 0, 읽기 위험 후보 476개 문장 부분을 추출하고 수사·조수사 및 주요 다의어 문맥을 검토했으며 현재 원문에 맞는 보정 64개를 반영했다. 자동 생성을 전량 언어 검수로 간주하지 않는다.
- 카드 안 모퉁이의 별도 컨테이너에 `새 단어` 또는 마지막 학습일 기준 `n일 전`을 표시한다. 당일 재학습은 `0일 전`이며 undo·재개 시 복원된 프로필을 따른다.
- 학습 개수 설정 근처에 선택 범위의 오늘 복습 단어 수를 표시한다. 복수 용법과 별칭은 중복 제거하며 양수일 때만 요청 문구를 표시한다.
- 전체 자동 검사 51파일 284개와 빌드 통과. 데스크톱 Chromium 24개, 터치가 활성화된 390×844 모바일 Chromium 에뮬레이션 13개 조작 검증 통과. 실제 휴대폰·Safari 검증을 뜻하지 않는다. 기존 저장 스키마·점수·복습 예정일을 유지했다.

## 저장·게시 계약

학습은 변경된 프로필·진행 세션·undo를 IndexedDB의 단일 트랜잭션에 저장한 뒤 화면을 바꾼다. 기존 v2 원문을 보관하고 작은 이전 표시를 남기며, 옛 탭·revision 충돌에서는 덮어쓰지 않는다. v2/v3 앱 백업은 설정과 학습을 함께 복원하고 실패·중단 복구를 지원한다. 64장 초과 QR은 파일 백업으로 안내한다.

Pages CI는 전체 테스트·콘텐츠 감사·현재 선정의 `jlpt:audit --require-target`을 통과한 버전만 게시한다. `release.json`의 commit과 indexSha256로 실제 공개 버전과 HTML을 대조한다. 로컬 검증/콘텐츠의published 원장은 웹 게시 성공과 다르다. 사용자가 요청한 완료 후 Git push → 실제 게시 확인 → 비강제 컴퓨터 종료 순서를 따른다.
